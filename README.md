# Innov'Events Manager

Application web et mobile de gestion événementielle pour l'agence Innov'Events.

## Prérequis
- Docker et Docker Compose installés
- Git

## Installation et lancement en local
1. Cloner le dépôt : `git clone https://github.com`
2. Entrer dans le dossier : `cd innovevents-manager`
3. Basculer sur la branche dev : `git checkout dev`
4. Lancer les conteneurs : `docker-compose up -d --build`

## Accès aux services
- Site Web : http://localhost:8080
- Application Mobile : http://localhost:8081
- Base de données (Adminer) : http://localhost:8082
